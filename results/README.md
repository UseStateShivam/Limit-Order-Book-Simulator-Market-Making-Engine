# Simulation & Experiment Results

This directory contains output artifacts produced by runs of `lob_sim`:
- `run-simulation`
- `run-market-maker`
- `replay-data`

Each run writes structured outputs into its designated output subfolder:
- `run_metadata.json`
- `trades.csv`
- `execution_reports.csv`
- `market_events.csv`
- `equity_curve.csv`
- `strategy_decisions.csv`
- `summary.json`
- `report.md`
